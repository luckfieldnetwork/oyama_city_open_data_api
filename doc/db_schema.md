# 小山市オープンデータ データベース仕様書 (DB Schema Reference)

小山市オープンデータカタログ（全42データセット・全394ファイル）の月次自動取得バッチ処理により生成された単一 SQLite3 データベース (`oyama_opendata.db`) の構造および全38テーブルの全カラム詳細仕様です。

## 1. 概要とデータベース構造

```
scraping/
└── db/
    └── oyama_opendata.db    ← 単一の SQLite3 データベースファイル (全38テーブル)
```

- **単一DBファイル構成**: 管理情報および全データセットのテーブルを `db/oyama_opendata.db` 1つに集約。
- **直感的な英語テーブル名**: 全データセットに対して内容を直接表す英語名を付与。
- **1データセット = 1テーブル**: データセット内に存在する複数の過去月次/年度別CSVを1つのテーブルに縦結合（UNION）して格納。
- **`_source_file` カラム**: 元CSVファイル名を全データテーブルの第1カラムに保持。
- **非CSVファイル**: PDFやExcel等の非CSVファイルは本体を `csv/non_csv/` に保存し、`sys_files` テーブルで状態管理。
